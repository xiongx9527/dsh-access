# 3088 移动端访问规格

## 抽屉导航

- 当浏览器视口进入移动端断点时，工作区/会话侧栏默认隐藏，主会话区域占据可用宽度。
- 移动端显示菜单按钮；点击后从左侧打开导航抽屉并显示遮罩。
- 点击遮罩、关闭按钮或切换会话后关闭抽屉。
- 抽屉内部独立滚动，不阻止主页面必要的触控滚动。
- 桌面宽屏继续显示现有侧栏，不增加移动端遮罩和浮动菜单。

## 安全区域和触控

- 移动端设置 `viewport-fit=cover`，并使用 `env(safe-area-inset-top/right/bottom/left)` 保护刘海、状态栏、圆角和 Home 手势区域。
- 顶部导航、底部 composer、浮动聊天入口和抽屉 footer 不得被安全区域遮挡。
- 菜单、关闭、发送和复制等高频控件提供适合触控的点击面积。
- 抽屉遮罩不发生事件穿透；输入框获得焦点、软键盘出现和页面滚动时，composer 仍可见且可操作。
- 移动端样式只在响应式断点生效，不改变桌面宽屏的布局和交互。
