# Outcome

提升 `dsh-access` 在 3088 网关上的远程访问稳定性、移动端体验和大响应传输效率，同时保持现有账号认证、Admin/Guest 权限隔离、3080 loopback 上游和统一登录入口不变。

# Scope

- Cloudflare 临时隧道使用更稳定的 HTTP/2 传输协议。
- cloudflared 下载支持 PATH 优先、本地缓存、平台资产兼容和多源回退；下载失败提供可操作错误信息。
- 用户明确开启公网访问后，dsh-access 重启时自动恢复隧道；用户手动关闭后取消自动恢复。
- 隧道恢复或 URL 变化后刷新状态、二维码和公网地址；恢复失败显示错误状态但不绕过登录保护。
- 3088 网关对满足条件的大型 JSON/text 响应协商 gzip/Brotli 压缩；SSE、WebSocket、HTML 注入流程、已压缩内容和小响应不走通用压缩。
- 响应压缩发生在 dsh-access 完成工作区/会话过滤和其他响应改写之后。
- 3088 网关访问在手机窄屏下使用完整抽屉式工作区/会话导航，并加入刘海、状态栏、Home 手势区和软键盘安全区域适配。
- 移动端增加触控友好的点击区域、遮罩关闭、滚动和输入区域处理；桌面宽屏保持现有布局。

# Non-goals

- 不引入公网 PIN、第二套账号认证或第二套会话系统。
- 不恢复或新增 dsh-pocket 的 3081 独立代理入口。
- 不改变 3080 loopback 上游、3088 统一登录网关或现有 Admin/Guest 权限模型。
- 不直接复制 GPL-2.0 的 dsh-pocket 源码；仅参考其可观察行为，在 dsh-access 中独立实现。
- 不在本 change 中实现插件自更新、自动 npm 更新或桌面端进程管理。
- 不改变桌面宽屏页面的用户可见布局和操作流程。

# Acceptance examples

- A1：Cloudflare 隧道启动参数包含 HTTP/2 传输配置，现有 URL 发现、停止、错误和 WebSocket 转发行为保持可用。
- A2：PATH 已存在 cloudflared 时优先复用；缓存命中时不重新下载；支持当前平台发布资产名和缓存二进制名；所有下载源失败时返回不泄露密钥且包含恢复建议的错误。
- A3：用户在远程访问页开启公网访问后，dsh-access 持久化“应保持开启”状态；重启并确认 3088 网关就绪后自动恢复新隧道，旧 URL 不被错误复用，二维码和页面状态更新。
- A4：用户手动关闭公网访问后清除恢复状态；后续 dsh-access 重启不再自动启动隧道；自动恢复失败不影响 3088 登录网关启动。
- A5：公网隧道仍然只通过 3088 访问管理登录；自动恢复不会引入匿名公网访问或绕过 Admin/Guest 会话校验。
- A6：支持 gzip/Brotli 协商的大型 JSON/text 响应被压缩，浏览器可自动解压；SSE、WebSocket、HTML 注入响应、已经压缩的响应和小响应不被通用压缩。
- A7：带工作区/会话权限过滤的响应先完成过滤和改写，再进行压缩；`Content-Encoding`、`Content-Length` 和缓存头保持一致。
- A8：手机宽度访问 3088 时，工作区/会话侧栏默认收起，菜单按钮可以打开左侧抽屉；点击遮罩或切换会话可以关闭，抽屉内容可滚动。
- A9：手机窄屏页面的顶部、底部输入区和浮动控件避开 safe-area；软键盘打开时输入区和发送按钮仍可操作；触控目标满足移动端点击需求。
- A10：桌面宽屏访问 3088 时保持现有侧栏、会话区、设置页和远程访问页布局；移动端改动不影响账号权限和远程访问功能测试。
- A11：自动化测试覆盖隧道 HTTP/2 参数、恢复状态生命周期、下载回退/缓存、压缩协商和移动端导航状态；项目构建成功。

# Constraints and invariants

- 任何公网 URL 都必须继续进入 3088 访问管理登录页。
- 手动关闭是明确的用户意图，优先级高于历史自动恢复标记。
- 压缩不得在权限过滤之前发生，也不得缓冲或改写 WebSocket/SSE 实时通道。
- 只在窄屏媒体条件下启用移动导航样式；桌面布局保持兼容。
- cloudflared 下载缓存目录使用访问管理自己的目录，不复用 dsh-pocket 的运行状态或令牌文件。
- dsh-pocket GPL-2.0 代码不直接复制到 BSD-3-Clause 项目。

# Decisions

- 采用 dsh-access 账号密码作为唯一访问控制，不采用 dsh-pocket 的 8 位公网 PIN。
- 采用 3088 网关作为唯一局域网/公网入口，不新增 3081。
- 自动恢复只恢复用户明确开启过的公网隧道；手动关闭后不恢复。
- 压缩采用浏览器协商的 Brotli 优先、gzip 兜底，并对不适合压缩的流量跳过。
- 移动端完整抽屉、安全区域和触控优化作为同一客户端适配范围实现，使用响应式条件隔离桌面布局。
- 下载和压缩逻辑独立重写，不直接移植 dsh-pocket 源文件。
